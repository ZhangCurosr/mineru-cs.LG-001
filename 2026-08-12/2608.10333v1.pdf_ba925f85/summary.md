# 论文速读：MERA: Model Evolution and Routing with Skill Adaptation for Agentic Systems at Scale

## 一句话总结
本文提出 MERA，一种以单次模型调用为适应单元的多轮演化协议，通过 SkillBook 程序化记忆、LoRA 适配器微调与输入型路由器的联合更新，并在可执行验证器的保守准入机制下持续迭代小模型能力，最终以 60.8% 的部署成本实现接近强模型的智能体性能。

## 研究问题与动机
- 现有智能体系统按任务粒度将请求路由至廉价小模型以降低成本，但小模型能力固定，节省上限受限于其已有水平。
- 生产环境在线轨迹自然蕴含适配信号，但直接修改服务策略风险高，廉价模型可能静默失败，已学适配器或模板在未见分布上易退化。
- 智能体工作流内含异构步骤（推理、格式化、工具参数构造等），单一粒度的任务级路由无法精细区分同一工作流内的难易调用。
- 现有路由、技能库与微调方法多独立评估，缺乏将它们统一于共享可执行轨迹并经由联合重放保守准入的系统层机制。

## 核心贡献（创新点）
- 提出 verifier-backed 多轮模型演化协议，将单次调用作为适应单元并分离观察与准入决策；与仅依赖路由或静态技能缓存的方法本质区别在于主动提升小模型自身能力而非仅绕行。
- 设计 Skill → LLM → Router 的依赖尊重更新调度，确保适配器训练使用当期 SkillBook 过程、路由器标签反映当期学生表现；区别于并行独立更新，该调度避免证据过期导致的性能退化。
- 引入基于可执行验证的联合重放准入机制，仅当 SkillBook、适配器与路由器的组合状态在 held-out 重放上保留任务质量时才正式部署；与仅凭孤立组件指标或模型置信度决策的机制本质区别在于以端到端可执行正确性为唯一放行标准。
- 在 HumanEval+MBPP 与 TAU-2 上验证协议有效性，证明 4 轮适应可将 1.5B 模型通过率提升 21 个百分点，并在验证器后备退下以 60.8% 成本达到接近大模型的部署效果。

## 方法详解
- **运行时路由与验证保护**：路由器仅观察当前调用的序列化 prompt，从强模型、廉价模型与可选专业学生模型中选择；执行后由验证器检查 schema 合法性、工具调用合规性、可执行测试或下游成功；验证失败则触发强模型回退并完整记录事件。
- **轨迹标准化与三路证据流**：将运行时 trace 规范化为 step slice，包含 prompt、局部上下文、工具 schema、生成输出、验证结果、重试次数与技能分配；同一 slice 按不同监督格式分别供给 SkillBook 统计、路由器训练与 LLM 适配器训练，无需组件间共享相同标注格式。
- **SkillBook 外部程序记忆**：聚合重复出现的 prompt 签名与局部执行模式，结合静态任务格式指令与有界成功示例及常见陷阱模式，以 prompt 前缀形式注入新任务，绝不返回相同 prompt 的存储答案，防止信息泄露。
- **LLM 适配器演化**：在 SkillBook 已更新的前提下，选取廉价模型失败或路由器与 SkillBook 证据冲突的硬样本进行 LoRA 微调，支持 SFT 与可选 GRPO 两阶段训练，直接提升小模型独立解算能力。
- **路由器训练**：使用冻结的 Qwen3-Embedding-0.6B 提取 prompt 特征并搭配类平衡逻辑回归头；标签由可执行小模型结果生成（验证通过为 cheap，否则 strong），阈值在独立校准 shard 确定，评估任务与训练/校准严格隔离。
- **联合重放准入**：每轮更新后在 held-out 集上运行候选组合，归一化成本按 `(小模型成本 + 触发回退的大模型成本) / 始终调用大模型成本` 计算；仅当重放不降低任务通过率且改善成本或回退风险时才放行，否则保留为实验工件。

## 实验与结果
- **设置**：HumanEval+MBPP 合并为 546 训练任务与 582 验证任务（disjoint identifiers，零 prompt 重叠）；小模型 Qwen2.5-Coder-1.5B-Instruct，强模型 GPT-5.6 Luna；TAU-2 使用 35 题固定划分进行适配器消融；3 个独立训练 seed。
- **直接小模型演化**：4 轮适应后 HumanEval+MBPP 上 Base SLM 为 28.7%，Multi-cycle SFT 提升至 44.2%，SFT+GRPO 进一步达 49.7%。
- **验证器后备部署**：MERA 路由器 + 验证器回退策略达到 88.3% pass，归一化成本仅为始终 Luna 的 60.8%；RouteLLM-style + fallback 为 87.0%/97.4%，FrugalGPT-style 为 85.5%/106.7%，系统优势来自演化后的 SLM 而非预路由精度。
- **TAU-2 工具使用迁移**：适配后 Qwen3.5-2B 从 14/35 提升至 18/35，匹配未适配的 Qwen3.5-4B 端点（17/35）；配对 McNemar 检验 p=0.172，统计功效不足但验证了协议在 multi-turn tool-use 场景的可行性。
- **财务盈亏**：500 行适应设置下一次性训练成本 $281.25，每日节省 $1.35，名义盈亏平衡点 8.68 天，保守（70% 实现率）为 12.47 天。

## 相关工作脉络
- **LLM 路由（FrugalGPT, RouteLLM, BEST-route）**：利用提示特征、预测质量或偏好数据决定降级时机；本文将其降为部署支撑，强调路由标签必须基于可执行验证而非模型置信度，且实验表明预路由精度并非质量保持的主因。
- **智能体优化（ReAct, LATS, AgentSwarm, ToolLLM）**：通过工具使用、推理-行动循环或图优化提升 agent 策略；本文指出这些工作通常将模型选择与可复用过程视为固定设定，未解决部署系统如何利用自身轨迹持续更新模型组合的问题。
- **模型专业化与技能库（Distill-Step-by-Step, SkillX, Agent-R）**：侧重蒸馏或外部技能构造；本文强调部署环境下的专业化具有条件性，失败需触发回退，并将技能定义为程序化 prompt 记忆而非答案缓存。
- **Agent 评估基准（WebShop, TAU-bench, SWE-bench, OSWorld）**：提供含可执行/断言验证的真实环境；本文利用此类基准的可执行性构建保守准入重放管道，指出单请求粒度难以覆盖长工作流内异构步骤的适配需求。

## 局限性与未来方向
- 路由标签与学生准入质量高度依赖验证器覆盖度，遗漏语义失败模式会导致重放高估降级安全性。
- "simple-step-first" 策略偏向窄且可核查的局部子图，长程复杂推理的难度短期内仍会堆积于强模型。
- 评估为 trace-centric 重放而非完全在线，策略变更引发的分布偏移无法被重放完全捕获。
- 技能推广假设重复局部子图可被规范化为稳定模板，高度异构的任务难以从中获益。
- 学习到的预路由器效果较弱，部署质量保持主要依赖验证器与回退机制而非准确的前置路由。
- 最强证据集中于代码生成，TAU-2 样本量小功效不足，跨领域泛化性与非平稳工作负载下的表现尚待验证。

## 研究启发与可借鉴点
- **观察与准入解耦**：将在线轨迹收集与离线联合重放准入分离，避免生产环境直接应用不稳定更新带来的静默退化，可迁移至任何需持续迭代的 agent 服务系统。
