# 论文速读：Beyond Detection Accuracy: Measuring Explanation Cost, Stability, and Utility for Resource-Aware IoT Intrusion Detection

## 一句话总结
本文构建了一个针对 CICIoT2023 的二分类、泄漏安全数据集，系统联合评估了 LR、DT、RF、XGBoost 四种模型在预测效果、TreeSHAP 解释计算成本、预测保持扰动下的局部稳定性以及基于验证校准的选择性解释代价–覆盖度权衡。研究证明，在资源受限 IoT 场景下，应同时看检测指标、架构相关解释成本、稳定性与调用策略，而不能仅凭准确率或“是否有解释”决定部署。

## 研究问题与动机
- 现有 IoT 入侵检测研究常以预测准确率为核心，却把事后解释当作计算成本为零的后续步骤，忽视解释实际消耗的推理延迟、吞吐与内存，不适合边缘网关部署。
- 高不平衡与分布依赖导致单一准确率/阈值易误导；误报会消耗分析师精力，且不同模型在 FPR、召回、规模、解释开销上可能差异显著，需要多维度比较。
- 已有 XAI-IDS 工作强调可用性与若干评测维度，但往往未在同一协议下把绝对解释耗时、相对于预测的开销比例、解释稳定性与选择性调用策略一起评估到可操作决策层面。
- 数据层面，CICIoT2023 存在大量精确重复与标签碰撞风险，若不进行哈希级去重与划分控制，评估可能受特征向量泄漏影响。

## 核心贡献（创新点）
- 基于原始 39 维特征的精确哈希审计构建泄漏安全二进制 CICIoT2023 语料：去除非有限值、保守移除跨原始标签冲突哈希、精确去重并以哈希确定性划分，避免训练/验证/测试间精确特征泄漏。
- 在自然分布与平衡敏感性测试下联合比较 LR/DT/RF/XGBoost 的检测质量与资源成本：用精确指标替代唯准确率视角，并展示解释成本随架构差异巨大，预测效率不等于解释效率。
- 提出并对 TreeSHAP 给出可复现的成本–稳定性–选择性联合评测协议：用绝对时间、吞吐、解释/预测比与预测保持扰动下的 Top-K 重叠、排名、方向与幅度漂移度量，避免只报告相对比例的误导性结论。
- 基于验证集校准的Selective-XAI策略实现代价–覆盖度权衡：在不使用测试标签的前提下，通过风险触发器保留高安全相关覆盖，同时在平衡测试上获得可观计算节省。
- 针对高原生重要性的 Number 特征做定向消融，说明原生特征重要性不等于不可替代因果依赖，强调解释前需验证特征完整性与预测依赖。

## 方法详解
- 数据质量控制：统计 309 个 CSV 中的缺失与非有限单元格，移除非有限行后对全量有效样本计算 39 维特征完整哈希；识别精确重复组与跨原始标签/攻击族碰撞哈希，并保守移除全部跨原始标签哈希后再去重。
- 泄漏安全划分：对保留的安全唯一哈希按确定性哈希分配划分 train/val/test（70/15/15），三份之间精确 39 维特征哈希重叠为零。
- 模型与训练控制：LR 使用 `SGDClassifier(loss="log_loss")`，五轮，训练集全部样本；DT/RF/XGBoost 使用相同确定性 5,000,000 训练样本，固定超参与平衡权重，测试集不参与调参与重训。
- TreeSHAP 成本测量：在平衡主样本 5,000 条上用不同 batch（1/10/100/1,000/5,000）记录预测与解释延迟，计算 `O_XAI = T_explain / T_predict` 与 `C_XAI = T_explain − T_predict`，并统计每样本微秒级延迟、吞吐与内存前后差值。
- 稳定性评估：以 100 条基样本（各 50 攻击/良性）生成候选扰动，仅接受满足预测类别不变且攻击置信变化 ≤ 0.05 的扰动；用 Top-5 Jaccard、Spearman、有符号 cosine 与归一化 L1 漂移衡量，并以基样本为统计单元做 10,000 次百分位 bootstrap 置信区间。
- 选择性解释策略：P0 全解释；P1 仅解释预测攻击；P2 仅解释不确定区间；P3 解释攻击或不确定；P4 基于验证假阴性的风险阈值，目标约 95% 假阴性解释覆盖，测试标签不参与校准。

## 实验与结果
- 数据集与划分：CICIoT2023 原始 46,776,700 行，移除非有限行后 46,775,660；精确重复率 54.8176%，跨原始标签碰撞 533,528；去重后得 20,600,823 唯一哈希，划分含 natural test 3,090,099 与 balanced sensitivity test 327,026。
- 预测性能：XGBoost 自然与平衡测试 F1 最高（0.985597 / 0.983653），PR-AUC 与 ROC-AUC 最优；RF 假阳性率最低（0.002269）；LR 在 0.5 阈值下 FPR 高达 0.308367，F1 优化阈值 0.11 进一步放大误报。
- 解释成本：在 5,000 样本处，RF TreeSHAP 耗时 700.7588 s（吞吐 7.135 samples/s，开销 28,217×）；DT 5.6427 s（886.10 samples/s，13,025.6×）；XGBoost 1.4711 s（3,398.84 samples/s，357.99×），绝对成本与扩展性最优。
- 稳定性：ε=0.01 下，RF 基样本层面 Top-5 Jaccard 0.885、Spearman 0.985、cosine 0.971、L1 漂移 0.097，整体最稳定；DT 在 Top-5 与方向上亦很高；XGBoost 方向与排名仍高但 Top-5 重叠与幅度漂移更大。攻击样本普遍比良性样本幅度漂移更高、cosine 更低。
- 选择性解释：平衡测试 90% FN 覆盖对应节省约 28–32%，95% FN 覆盖对应节省约 15–23%；自然攻击主导测试因几乎需解释几乎所有攻击，95% 目标下仅节省 1.7–2.6%。P1/P2/P3 单独使用无法兼顾覆盖与成本。
- 特征完整性：Number 原生重要性极高且 KS 最大（0.9391），但从 XGBoost/DT 中移除后 F1 变化分别仅为 −0.000023/−0.000028 与 −0.000450/+0.000257，说明高原生重要性不等价于不可替换依赖。

## 相关工作脉络
- Le et al. 在 IoTID20/NF-BoT-IoT-v2/NF-ToN-IoT-v2 上使用 DT/RF 与 SHAP，侧重可用性与多数据集对比，未显式联合评估 TreeSHAP 绝对成本、预测保持稳定性与选择性调用策略；本文聚焦同一协议下的资源–覆盖权衡。
- Patil et al. 在 CICIDS2017 用 LIME+DT/RF/SVM/投票 ensemble，侧重可解释框架而非解释计算负担与稳定性；本文以 TreeSHAP 为主并给出延迟/吞吐与扰动协议。
- E-XAI 对黑盒方法在多个数据集上进行了描述精度、稀疏性、稳定性、效率、鲁棒性与完整性等系统评测，但未在同一协议下把解释成本与预测成本做联合比例分析，也未进行哈希级泄漏安全划分验证；本文补齐这些操作化维度。
- Wang et al. 考察 SHAP/LIME 在 IoT IDS 上的透明度，仍属方法应用层面；本文引入验证校准的选择性解释与 prevalence-sensitive 成本–覆盖前沿。
- Munilla & Khammas 用 DeepFool 对 SHAP/LIME 施加对抗扰动以改变模型决策；本文扰动以预测保持与攻击置信变化 ≤ 0.05 为约束，更贴近运维中的局部稳定性与可重复性。
- 本文相对前作的定位：提供可复现的"预测–解释–稳定性–选择性调用”一体化评估，强调解释开销与架构相关、稳定性多维、以及调用策略在资源约束下的必要性。

## 局限性与未来方向
- 单一数据集与二分类任务，未做多类别攻击族联合评估与跨数据集泛化验证。
- 计时在主机上进行，未直接在边缘 IoT 网关或受限硬件上实测，结论不能直接外推到实际边缘部署。
- 内存统计基于前后 RSS 差，可能未捕获瞬态峰值；解释结论局限于 TreeSHAP，不宜直接推广到 LIME、model-agnostic SHAP 或其他 XAI。
- 扰动协议在选定连续流量特征与验证集分位数内约束，属于局部敏感度测试，非完整因果流量生成或全协议对抗评估。
- 稳定性不等于因果性或语义正确性；本文未进行人工分析师可用性/决策改善的人机评估。
- 未来可在真实边缘设备复现主机基准、扩展到多类别与多解释器对比、引入人类评估，以及研究更优的自适应选择调用策略。

## 研究启发与可借鉴点
- 采用“哈希级去重+跨标签保守过滤+确定性哈希划分”的数据管道，适合大规模 IDS 基准的泄漏安全复现。
- 把预测成本与解释成本分开度量并用绝对延迟与吞吐一起报告，避免只凭 overhead ratio 得出错误部署结论。
- 用预测保持扰动的多维稳定性（Top-K 重叠、排名、方向、幅度）评估 XAI 可靠性，并区分 pair 级与 base-sample 级统计单元。
- 基于验证集校准的 selective explanation 可作为通用资源分配策略，将 XAI 视为有限预算的操作资源而非必开后处理。
- 对高原生重要性特征做定向消融，帮助区分“重要”与“不可替代”，为后续特征治理与稳健解释提供依据。

## 关键术语表
- **CICIoT2023**：大规模实时 IoT 基准数据集，包含 105 设备与多类攻击流量。
- **TreeSHAP**：面向树模型的 Shapley 加性解释算法，能提供快速局部特征贡献估计。
- **泄漏安全划分**：在精确特征向量哈希层面保证训练/验证/测试无重复。
- **选择性解释（Selective XAI）**：按置信/风险策略决定哪些预测生成解释，以控制计算预算。
- **解释稳定性**：在小扰动下解释的稳定性，常用 Jaccard、Spearman、cosine 与 L1 漂移度量。
- **代价–覆盖度权衡**：在保留关键安全解释覆盖的同时降低解释计算开销。
- **FPR**：假阳性率，衡量良性流量被误报为攻击的比例。
- **PR-AUC**：精确率–召回率曲线下面积，更适合不平衡检测任务的聚合指标。

## 可复现要素
- 数据集：CICIoT2023 公开可获取；本文预处理与审计脚本、模型权重与结果已开源至 GitHub 并提供 Zenodo 归档（DOI: 10.5281/zenodo.21879038）。
- 代码/权重：开源，含 corpus 构建、预测评估、TreeSHAP 成本、稳定性分析与选择性解释全流程复现材料。
- 关键超参：LR 用 `SGDClassifier(loss="log_loss")`、5 epoch、balanced class weights；DT 用 `max_depth=20, min_samples_leaf=20`；RF 150 棵树、`max_depth=20, min_samples_leaf=20`、按特征数平方根选分裂；XGBoost 300 棵树、`max_depth=8, learning_rate=0.1`、行列子采样各 0.8、`min_child_weight=5`、histogram 方法；全局 seed 2026。
- 成本与稳定性：TreeSHAP 主样本 5,000、batch 1/10/100/1,000/5,000；扰动尺度 σ=0.01×IQR、限制 9 个连续特征、类别与置信变化约束；bootstrap 10,000 次。
