# 论文速读：Iterative Erasure Count Is Not an Affine-Invariant Concept Dimension

## 一句话总结
本文证明"迭代擦除计数"（iterative erasure count）不是一个仿射不变的概念维度指标：相同的潜在概念维度在可逆坐标变换下会给出不同的停止计数；作者区分了人口量与过程量，并证明了完整轨迹在度量一致传输下的仿射等变性。

## 研究问题与动机
1. **核心问题**：神经表示用多少个方向编码一个概念？现有文献常用"迭代空空间投影"（INLP等）拟合线性分类器、移除方向、重新拟合，以停止计数或累积移除秩作为"概念维度"的解释。
2. **已有工作的不足**：INLP原始论文将擦除计数解释为"受保护属性子空间"的维度；后续视频世界模型工作将"数十个方向"解释为分布式的物理变量。但这些做法混淆了过程相对量与内在语义维度。
3. **为什么不够**：一个可逆变换保持所有信息和预测能力，但改变欧氏几何；停止计数依赖特征度量、探针损失、正则化、协方差估计和停止规则等过程选择，而非概念本身。
4. **研究缺口**：现有协方差感知方法（MP、LEACE等）给出单步最小失真守卫，但未提供离散整数计数的非识别结果；规范自由度工作指出欧氏相似性可变，但未给出精确计数变化的理论分离。

## 核心贡献（创新点）
1. **证明迭代擦除计数的非识别性**：在人口高斯构造中，充分线性维度和最小守卫秩固定为一，但累积欧氏擦除计数从一个变为两个；这是精确整数变化结果，而不仅仅是连续量变化。
2. **建立完整轨迹的仿射等变定理**：证明了当正定度量、探针、正则化和断规则被一致传输时，累积度量-QR轨迹是仿射等变的；精确协方差度量是该定理的一个推论，而非默认的语义度量。
3. **扩展至全QR多元情形**：针对两输出最小二乘与完整QR去除的代数结构，证明累积编辑秩可以从$r$变为$2r$（即环境维度），而充分维度和最小守卫秩保持不变。
4. **有限样本桥接与视觉案例研究**：复现了动机论文的Adam/MSE/QR循环，在固定V-JEPA2特征上施加shear变换，展示了实用优化下轨迹的过程相对性；这些测试强调过程依赖性而非接触维度的估计。
5. **明确区分五种"维度"估计量**：生成维度、充分线性维度、交叉协方差秩、迭代擦除计数、线性守卫秩——它们不必一致，应分开报告。

## 方法详解
1. **五种估计量的形式化定义**：
   - 生成维度（Generating dimension）：数据生成标签规则使用的潜变量数量。
   - 充分线性维度（Sufficient linear dimension）：在给定模型下对Y足够的最小人口线性子空间维数$r$，即存在$B \in \mathbb{R}^{d \times r}$使$Y \perp X \mid XB$。
   - 交叉协方差秩（Cross-covariance rank）：$\mathrm{rank}\,\mathrm{Cov}(X, \phi(Y))$，仅捕获一阶矩。
   - 迭代擦除计数（Iterative erasure count）：停止时间，多变量更新时应单独报告累积编辑秩。
   - 线性守卫秩（Linear guarding rank）：满足指定守卫条件的最小干预秩。

2. **算法框架（Algorithm 1：声明的累积度量-QR擦除）**：
   - 给定中心特征$X$、固定正定度量$G \succ 0$、探针规则和停止规则，初始化$U_0 = [\ ]$、$T_0 = I$。
   - 第$k$步：拟合系数块$B_k = \mathrm{Probe}(XT_{k-1}, Y)$；对$U_{k-1}$残差化并进行$G$-正交QR得$Q_k$；若$Q_k$为空或停止规则触发则停止；否则$U_k = [U_{k-1}, Q_k]$，$T_k = I - U_k U_k^\top G$；分别记录迭代计数和$\mathrm{rank}(I - T_k)$。
   - **关键**：度量不在编辑后重新计算，所有度量、探针、正则化、数值容差和停止规则都是估计量的一部分。

3. **仿射等变定理（Proposition 2）**：
   - 设$G_X \succ 0$是从完整表示固定的系数度量；第$k$步探针返回系数块$B_k$，追加其度量正交化列空间到$G_X$-正交基$U_k$，编辑为$T_k = I - U_k U_k^\top G_X$。
   - 对于$Z = XA$（$A$可逆），传输度量$G_Z = A^\top G_X A$；若探针等变（$B_k^Z = A^{-1}B_k$）、正则化随$A$传输、非子空间断规则等变解析，则对所有$k$有$ZT_k^Z = (XT_k)A$；分数、累积编辑秩和所有基于分数的停止计数在两种参数化下相同。
   - **证明要点**：若$U_k^Z = A^{-1}U_k$，则$(U_k^Z)^\top G_Z U_k^Z = I$，且$AT_k^Z = T_k A$，由归纳法得证。

4. **人口一阶构造（Theorem 1）**：
   - 设$S, N \overset{iid}{\sim} \mathcal{N}(0,1)$，$L = \mathrm{sign}(S)$，$X_a = (S + aN, N)$。
   - 对于任意有限脊回归权重$\lambda \geq 0$：当$a = 0$时迭代计数和累积编辑秩为1；当$a \neq 0$时为2。
   - **证明思路**：脊回归系数与$(1+\lambda, -a)^\top$成比例，仅当$a=0$时与交叉协方差方向$(1,0)^\top$平行；$a \neq 0$时第一次编辑后保留的非零交叉协方差导致第二次编辑。

5. **全QR多元定理（Theorem 2）**：
   - 对两输出情形$r=2$：$a=0$时迭代计数为1、累积编辑秩为$r=2$；$a \neq 0$时迭代计数为2、累积编辑秩为$2r=4$（环境维度）。
   - 充分线性维度和最小独立守卫秩在所有$a$下均为$r$。

6. **有限循环QR桥接**：
   - 实现动机论文的序列投影循环：$\theta \sim \mathrm{Unif}[-\pi, \pi]$，$S = (\sin\theta, \cos\theta)$，$N \sim \mathcal{N}(0, 0.5I_2)$，$X_a = (S + aN, N)$。
   - Adam/MSE探针，100轮，学习率$10^{-3}$，权重衰减$10^{-4}$，80/20固定划分。
   - 更新接受条件：保留$R^2 \geq 0.1$且圆环MAE $\leq 80°$。

## 实验与结果
1. **人口构造验证**：
   - 表5显示：脊回归剪切计数$a=0$时为1，$a \neq 0$时为2（差异+1）；连续目标下欧氏计数$\kappa=1$时为2，$\kappa \geq 3$时为8（差异+6）；精确协方差度量始终为2。

2. **有限循环QR实验**：
   - $n=4000$时，$a=0$在所有20次运行中$K=1$（$P(K \geq 2)=0$）；$a=1$在所有20次运行中至少接受2次更新（$P(K \geq 2)=1$），平均$K=5.75$（范围3–8），2次右删失。
   - 小样本$n=1000$时仅15/20的$a=1$运行接受第二次更新，与定理1的连续残留幅度一致。
   - 批大小64/128/256下分离保持不变。

3. **V-JEPA2特征案例研究（100DOH）**：
   - 层21，验证AUROC=0.885；DINOv2层12，AUROC=0.858。
   - 经映射坐标重标准化后，均值秩10 AUROC在$\kappa=1$时为0.599，$\kappa=10$时为0.791，配对bootstrap区间[.110, .275]。
   - 无重标准化时：$\kappa=10/100/1000$分别为0.802/0.841/0.853，说明效应不仅来自坐标缩放。
   - 未收缩 empirical 协方差干预：所有映射下轨迹完全相同（秩1: 0.587，秩10: 0.518），最大预测差异$2.11 \times 10^{-6}$，符合Proposition 2推论。
   - 20个Haar正交映射也复现了完整欧氏AUROC轨迹，最大差异$4.27 \times 10^{-6}$。

4. **强攻击者实验（训练内角色划分）**：
   - 秩0 AUROC在所有映射下均为0.822。
   - 秩10时，身份映射平均0.665，五个$\kappa=10$映射平均0.776，配对差异均值+0.111，25/25对为正。
   - 秩1差异均值+0.033，秩2差异均值+0.060。

5. **Metric依赖的non-monotone曲线**：
   - 100DOH：Euclidean/OAS在秩1后为0.827/0.586，秩10后为0.598/0.494。
   - TouchMoment：秩1后为0.924/0.811，秩10后为0.778/0.447。

6. **交叉拟合校准**：
   - 合成 Rank-1 概念：empirical MP/SAL在$n_A=100$时留存的AUROC为0.881，即使已知人口守卫秩为1；oracle为0.499。
   - 100DOH-max LEACE-OAS：$n_A=100$时0.876，$n_A=6000$时0.647；TouchMoment：$n_A=100$时0.927，$n_A=4000$时0.626。

## 相关工作脉络
1. **INLP（Ravfogel et al., 2020）**：迭代空空间投影，原始论文将其解释为"受保护属性维度"；本文不否定其线性守卫解释，但指出停止计数本身不是仿射不变的语义维度。
2. **Mean Projection / LEACE / SAL（Belrose et al., 2023; Haghighatkhah et al., 2022; Shao et al., 2023）**：单步闭式最小失真守卫；本文承认其价值，但强调协方差是一种选定的几何而非普适语义度量，且本文给出完整轨迹等变定理。
3. **Gauge Freedom（Cain, 2026）**：证明函数保持的可逆变换下欧氏相似性可变；本文贡献更精确：离散整数计数变化，而充分维度和守卫秩固定。
4. **Video direction study（Joseph et al., 2026）**：动机论文使用全QR去除估计视频物理变量维度；本文复现其Adam/QR循环并证明计数过程相对。
5. **Amnesic probing（Elazar et al., 2021）**：使用累积子空间作为反事实干预；本文指出移除方向计数用于调整干预大小而非定义仿射不变维度。
6. **Spectral Attribute Removal / RLACE**：SAL基于交叉协方差左奇异子空间；RLACE回答不同的攻击者相对优化问题；本文强调无论何种擦除器都需要明确声明估计量。

## 局限性与未来方向
1. **理论局限**：仿射定理和潜构造仅针对线性表示和线性干预；非线性、token级、空间、时间或因果概念组织未被涵盖。
2. **视觉案例局限**：聚焦单一V-JEPA2检查点和接触概念；DINOv2是图像编码器而非时间匹配的视频模型；接触标签含对象配置捷径和时间相信息，非纯物理接触原语。
3. **有限实验局限**：循环桥接使用控制分布而非真实视频激活；未复现steering实验；minibatch大小部分基于声明值（动机论文未报告）。
4. **度量选择局限**：精确协方差度量仅是等变定理的一个特例，不意味着它是"语义正确"的度量；OAS和Ledoit-Wolf收缩不创建规范语义度量。
5. **统计验证局限**：描述性停止规则重用验证集进行层、正则化和秩选择，缺乏形式序贯误差控制；无未触碰的测试集验证。
6. **未来方向**：建立未来数据集的前瞻性协议；探索非线性等变框架；研究不同度量族的选择准则。

## 研究启发与可借鉴点
1. **估计量分离框架**：明确区分五种"维度"估计量（生成维度、充分线性维度、交叉协方差秩、迭代计数、守卫秩）并分开报告，可作为后续研究的标准化范式。
2. **仿射等变定理的实践意义**：若研究者可声明并传输正定度量，则累积轨迹具有过程相对不变性；这为"度量感知的擦除"提供了理论基础。
3. **正交映射作为数值sanity check**：使用Haar正交映射验证算法实现正确性（差异<$10^{-5}$），是一种可复用的稳健性测试策略。
4. **交叉拟合角色划分设计**：将训练数据划分为A（干预估计）、B（攻击者训练）、C（评估）三组，以诊断有限样本残留访问，该方法可迁移至其他干预研究。
5. **各向异性映射作为stress test**：通过显式声明的shear变换族检验方法对坐标选择的敏感性，比随机扰动更具解释力。

## 关键术语表
**Iterative Erasure Count（迭代擦除计数）**：通过反复拟合探针并移除其方向，直到停止规则触发的迭代次数，常被误解释为概念维度。

**Sufficient Linear Dimension（充分线性维度）**：使$Y \perp X \mid XB$成立的最小线性子空间维数$r$，是人口意义上的概念编码维度。

**Linear Guarding Rank（线性守卫秩）**：满足指定守卫条件（如攻击者风险不低于基线）的最小干预秩，依赖于攻击者类和损失函数。

**Affine Equivariance（仿射等变性）**：当度量、探针、正则化等被一致传输时，算法输出在可逆变换下保持等价关系的性质。

**Cumulative Edit Rank（累积编辑秩）**：第$k$步后编辑算子的秩$\mathrm{rank}(I - T_k)$，在多变量更新时不一定等于迭代计数。

**Moore–Penrose OLS（Moore–Penrose最小二乘）**：在协方差奇异时使用伪逆求解的最小二乘，选择最小欧氏范数系数，不满足仿射等变性。

**Transported Metric（传输度量）**：在坐标变换$Z=XA$下，系数度量从$G_X$传输为$G_Z = A^\top G_X A$以保持二次型不变。

**Cross-fitting（交叉拟合）**：将数据划分为估计角色、训练角色和评估角色，以分离有限样本估计误差与真实守卫效果的方法。
