# 论文速读：Recovering Wasted Compute in Autoresearch Agents

## 一句话总结
本文针对基于树搜索的自动研究（autoresearch）智能体在处理表格机器学习任务时的共性缺陷，指出其大量计算预算被浪费在重复调试同一Bug、跳过超参调优、陷入无效搜索路径及忽略数据分析信号上；通过引入共享调试上下文、预算感知超参控制回路及Thompson Sampling回溯策略等纯架构干预，在未更换底层大语言模型的前提下显著恢复了浪费的计算资源并大幅提升最终性能。

## 研究问题与动机
1. **核心问题**：现有树搜索型autoresearch智能体（如AIDE、ML-Master）在执行端到端表格机器学习任务时，计算预算未被有效转化为高质量模型迭代，而是大量消耗于冗余试错与低效探索。
2. **重复调试同一Bug**：搜索树的各分支彼此隔离，相同的API版本不兼容、废弃调用或运行时约束会在不同节点被反复独立发现与修复，造成严重的计算冗余。
3. **过早终止与跳过超参调优**：基于表面收敛的终止条件使智能体在获得少数有效解后提前退出，未能利用剩余预算执行系统性的超参数优化，导致潜力被白白留在桌面上。
4. **搜索死路与数据信号脱节**：随机回溯策略易使智能体困于无效代码路径直至预算耗尽；同时，即使向上下文注入探索性数据分析（EDA）结果，智能体也往往不予采纳，无法将分析洞察转化为下游建模决策。

## 核心贡献（创新点）
1. **全局共享的Debug Consultant机制**：通过压缩错误堆栈并维护跨搜索树分支共享的运行时约束注册表（禁止模式与已验证修复清单），在节点生成前注入已知失败约束。**与现有方法的本质区别**：AIDE/ML-Master等框架的知识仅局限于单分支局部上下文，而本设计将环境约束升级为全局可传播的资产，彻底阻断跨分支重复试错。
2. **预算感知的超参调优控制层（HPO Enforcement）**：引入LLM裁判对节点调优质量进行0-3级量化评分，并结合剩余预算动态调整搜索奖励与提示词，强制智能体在后期将算力倾斜至结构化超参搜索。**与现有方法的本质区别**：不同于传统AutoML的固定网格/随机搜索或单纯提示词指导，该机制通过控制回路将调优深度与搜索阶段（早期广探索 vs 后期深开发）显式耦合，防止早熟收敛。
3. **Thompson Sampling增强的回溯策略**：以Beta分布建模兄弟节点的潜力后验，通过概率抽样选择扩展节点，并在检测到重复错误时回溯至首次分叉点重新采样。**与现有方法的本质区别**：替代了主流Agent的随机回退或纯UCT贪婪选择，在极低的样本复杂度下实现探索与利用的自适应平衡，显著提升搜索稳定性。
4. **EDA失效诊断实验**：通过向上下文注入对抗性/误导性EDA结果，定量检验现有智能体是否真正利用数据分析洞察；发现实际采纳率极低，揭示“看似执行数据科学流程实则脱离数据信号”的设计漏洞。**与已有工作的本质区别**：跳出传统仅以最终指标评价成功率的范式，直接量化Agent对领域先验信号的响应与整合能力，为后续数据意识模块设计提供明确靶点。

## 方法详解
- **Context-aware Debug Consultant（上下文感知调试顾问）**：
  - **错误压缩**：节点崩溃时，将冗长traceback压缩为错误类型、简短签名与失败策略的紧凑记录，避免上下文窗口膨胀。
  - **共享Bug注册表**：累积所有压缩记录，提炼出`BANNED`（如`lgb.train(..., verbose_eval=N) → TypeError`）与`USE`（如`callbacks=[lgb.log_evaluation(period=N)]`）清单，新节点立即继承全量历史约束。
  - **约束注入**：生成阶段将禁止列表追加至提示词；调试阶段检索相关记录提供针对性建议，使修复从盲猜转为知情决策。
  - **确定性控制规则**：执行超时报错或空日志被视为终端死路，直接剪枝而非随机重试。
- **Hyperparameter Tuning Interventions（超参调优干预）**：
  - **提示层**：通过`additional_notes.txt`追加结构化调优指令（建立验证基线→廉价探针识别敏感参数→聚焦高影响参数精细化→ plateau时切换至exploitation）。
  - **控制回路层**：执行后用LLM裁判按0-3量表（NONE/MINIMAL/MODERATE/EXTENSIVE）评分。AIDE中调整验证指标：`metric_adj = metric_base + 0.1*s*(r_hpo + r_div + r_corr)`（`s`为基线指标量级），ML-Master中直接叠加至UCT奖励（如`+0.25*hpo_score`）；弱调优全程惩罚，强调优仅在搜索后期奖励，引导“先广探索后深开发”。
- **Thompson Sampling-enhanced Backtracking（Thompson采样回溯）**：
  - 每个兄弟节点$i$维护`Beta(α_i, β_i)`分布表示其质量后验，初始为均匀分布`Beta(1,1)`。
  - 选择步骤：从各候选分布采样`θ_i`，扩展得分最高者`s* = argmax θ_i`。
  - 执行后按归一化奖励`r∈[0,1]`更新参数：`α_new = α_old + r`，`β_new = β_old + (1-r)`。
  - 当检测到相同错误沿路径反复出现时，回溯至首次出现该错误的分支点，利用TS重新采样兄弟节点，将预算重分配
