# 论文速读：Retrieval–Corrected Conformal Prediction for Time Series

## 一句话总结
论文提出检索校正共形预测（RCCP）方法，通过将时间序列残差的局部检索与标量共形校正分离，解决传统共形预测在校准过程中因时间依赖性和非平稳性导致的覆盖率失效和区间效率低的问题。

## 研究问题与动机
- 时间序列的预测误差不满足交换性假设，具有时间依赖性、异方差性和分布偏移，导致全局残差分位数无法适配当前预测上下文
- 现有局部校准方法（加权、自适应）往往通过软加权多个校准样本引入噪声，降低区间锐度
- 检索方法可直接选择相似历史残差作为局部证据，但检索得到的区间本身缺乏覆盖率保证
- 如何在利用检索提供局部信息的同时，有效校正剩余覆盖率误差，是一个未解决的问题

## 核心贡献（创新点）
- 将残差检索应用于共形预测，作为对校准样本广泛加权的直接替代，从相似历史预测上下文中选择残差作为局部证据
- 提出 RCCP 框架，将非对称检索区间与标量共形校正相结合，实现局部适应性与覆盖率保证的分离
- 建立基于归一化检索误差稳定性的覆盖率间隙界和渐近覆盖率理论结果
- 在标准基准和骨干预测器上实现目标覆盖率，取得最低 Winkler 得分，并减少严重漏覆盖

## 方法详解
- **检索知识库构建**：在预测时间 t 之前，将每个预测上下文编码为检索键 z_t = ψ_f(X_t, Ŷ_t)，存储到有序知识库 K_{t-1}；观测响应后，计算单侧残差 e^+_i = (Y_i - Ŷ_i)_+ 和 e^-_i = (Ŷ_i - Y_i)_+，分别存储以允许不同的尾部行为
- **残差检索**：使用 KNN 检索与查询键最相似的 K 个历史上下文，可应用距离加权 w_i(t) = exp(-d(z_t, z_i)/τ) / Σ exp(-d(z_t, z_j)/τ)
- **非对称检索区间**：分别从正负残差中计算 Q_{1-α/2} 分位数，构建不对称区间 ã_t = [Ŷ_t - R̃_t^-, Ŷ_t + R̃_t^+]
- **归一化检索误差校正**：在校准集上计算 B_j = max{(Y_j - Ŷ_j)_+ / R̃_j^+, (Ŷ_j - Y_j)_+ / R̃_j^-}，估计标量校正因子 ĉ = Q_{1-α}({B_j})
- **最终区间**：C_t^{RCCP} = [Ŷ_t - ĉ·R̃_t^-, Ŷ_t + ĉ·R̃_t^+]

## 实验与结果
- **数据集**：Air（PM10，12个位置）、Solar（DHI，50个位置）、Electricity（负荷转移）、Wind（MWH），按 40%/40%/20% 划分训练/校准/测试集
- **骨干预测器**：LSTM 和 Transformer，隐藏维度 128，batch size 256，学习率 10^-3，训练 150 轮
- **基线方法**：SCP、EnbPI、SPCI、NexCP、HopCPT、ResCP
- **主要结果**（α=0.1）：
  - Air+LSTM：RCCP Winkler 得分 92.44±0.35，显著优于最佳基线 HopCPT（101.57±0.48）
  - Solar+LSTM：RCCP Winkler 得分 26.08±0.67，优于最佳基线 ResCP（38.90±1.43）
  - 在全部数据集和骨干网络组合上均实现目标覆盖率（ΔCov 接近 0），且 Winkler 得分最优或次优
  - 宽度适应性比（Decile 10/Decile 1）：Air 达 2.30，Solar 达 20.86，超越所有基线
- **计算效率**：校准时间在合理范围内，显著低于 HopCPT（Air 上 70.94s vs 262.74s）和 SPCI（Air 上 70.94s vs 664.91s）

## 相关工作脉络
- **Split Conformal Prediction (SCP)**：基础方法，假设交换性，在全局残差上计算分位数；时间序列中因非交换性而失效
- **EnbPI/SPCI**：在线/自适应共形预测，通过滑动窗口更新校准；仍能捕获时间动态但区间适应性有限
- **NexCP**：构建测试依赖的加权残差分布，基于时间邻近性分配权重；RCCP 采用直接检索替代软加权
- **HopCPT**：使用现代 Hopfield 网络进行相似度加权；RCCP 采用更直接的 KNN 检索，避免额外模型训练开销
- **ResCP**：基于 reservoir 状态相似度重加权；RCCP 分离检索与校正，提高校准可靠性
- **RATD/TS-RAG**：检索增强时间序列预测；本文将其思想延伸至不确定性量化而非点预测

## 局限性与未来方向
- 检索表示质量直接影响区间效率，若嵌入无法捕获误差相关相似性则性能下降
- 尚未扩展到高维观测、多变量目标和多步预测场景，残差结构和不确定性可能跨维度和预测 horizon 变化
- 未来工作可研究检索-校正校准在高维和多变量时间序列中的应用

## 研究启发与可借鉴点
- **检索与共形预测的结合思路**：将检索用于选择局部证据、校正用于保证覆盖率的两阶段设计，可迁移到其他需要局部适应性的不确定性量化任务
- **归一化残差误差的标量校正**：将局部区间误差归一化后估计单一校正因子，既保留局部信息又简化校准过程，计算方法高效
- **非对称单侧残差分离存储**：分别处理正负残差以捕捉预测偏差的方向性，提升区间效率
- **宽度适应性分析**：通过分位数分层分析区间宽度与实际误差的关系，验证方法在高误差区域的适应性

## 关键术语表
- **Conformal Prediction (CP)**：一种分布无关的预测区间构建框架，基于校准残差的分位数提供覆盖率保证
- **Nonconformity Score**：衡量样本偏离程度的分数，在 CP 中用于构建预测区间
- **Exchangeability**：数据点的联合分布在置换下不变的假设，是标准 CP 理论成立的基础
- **Heteroskedasticity**：误差方差不齐性，时间序列中常见现象，导致全局校准失效
- **Winkler Score**：综合评估预测区间长度和覆盖率违反的度量指标
- **Retrieval Key**：编码预测上下文的向量表示，用于在知识库中检索相似历史样本
- **Coverage Gap**： empirical coverage 与目标覆盖率 1-α 之间的差异
