# 论文速读：Retrieval–Corrected Conformal Prediction for Time Series

## 一句话总结
提出RCCP（检索校正共形预测），通过检索相似历史残差构建不对称局部区间，再用标量共形校正因子校准覆盖误差，解决时间序列CP中残差非平稳、异方差导致的校准失效问题，在多个基准数据集和预测器上实现目标覆盖率与最优Winkler得分。

## 研究问题与动机
1. **时间序列共形预测的校准效率低下**：标准CP假设校准与测试得分可交换，但时间序列残差存在时序依赖、异方差和非平稳性，全局阈值在稳定期过于保守、在波动期不足，削弱覆盖率与区间效率权衡。
2. **局部校准方法间接且稀释关键证据**：现有方法（如加权、近期误差反馈、状态表征）通过软加权或额外自适应过程构建局部阈值，弱相关残差仍会影响区间，降低锐度；检索虽能直接选取相似残差，但所得区间本身无覆盖率保证。
3. **缺乏直接利用残差证据并校正覆盖误差的机制**：核心问题是如何使用检索残差构建尖锐局部区间，同时校正检索后剩余的覆盖误差，避免全局阈值或复杂自适应过程。
4. **预测区间需适应动态误差分布**：现代深度学习预测模型提高了点精度，但决策需要预测区间量化可能偏差，概率预测方法依赖模型假设，误设时名义不确定性无法转化为可靠覆盖率。

## 核心贡献（创新点）
1. **将残差检索引入共形预测，替代宽泛加权与额外训练过程**：从相似历史预测上下文中直接选取残差作为局部证据，与已有工作基于时间邻近或软加权残差分布的本质区别在于直接硬选择（或距离加权）最近邻残差。
2. **提出RCCP框架，结合不对称检索区间与标量共形校正**：检索提供局部残差证据构建非对称区间，共形校正仅估计一个标量缩放因子，与NexCP、HopCPT等通过加权估计测试特定分位数方法的本质区别在于分离局部区间构建与最终覆盖率校准两个步骤。
3. **给出基于规范化检索误差分布稳定性的覆盖率隙界与渐近覆盖率结果**：理论分析不依赖校准-测试可交换性，而是假设规范化检索误差分布在目标乘数处的稳定性，与标准CP理论适用条件的本质区别在于适应时间序列非平稳性。
4. **实验证明RCCP在所有设定下达到目标覆盖率且Winkler得分最低**：相比基线方法减少严重漏报，同时保持低校准开销，与EnbPI、SPCI等自适应方法相比在计算效率与覆盖有效性间取得更好权衡。

## 方法详解
**整体流程**：给定固定预测器$f$，将观测数据按时间分为训练集、校准集、测试集，校准集用于构建检索知识库并估计校正因子，测试集用于构建预测区间。

**检索知识库构建**：对每个预测时间点$t$，在响应$Y_t$观测前，将预测上下文编码为检索键$z_t = \psi_f(X_t, \widehat{Y}_t)$，其中$\psi_f$可使用输入窗口嵌入、预测器表征、点预测特征或外生变量的拼接。观测到$Y_t$后，计算单侧残差$e_i^+ = (Y_i - \widehat{Y}_i)_+$和$e_i^- = (\widehat{Y}_i - Y_i)_+$，分别存储以允许上下尾行为不同，形成知识库$\mathcal{K}_{t-1} = \{(z_i, e_i^+, e_i^-) : i < t\}$。

**残差检索**：用当前键$z_t$与知识库$\mathcal{K}_{t-1}$中的键计算距离$d(z_t, z_i)$（实验中使用欧氏距离），选取距离最小的$K$个过去索引$N_K(t) = \text{KNN}_K(z_t, \mathcal{K}_{t-1}, d)$。检索残差可按距离加权，权重$w_i(t) = \exp(-d(z_t, z_i)/\tau) / \sum_{j \in N_K(t)} \exp(-d(z_t, z_j)/\tau)$，其中$\tau$控制局部分布集中度；均匀权重对应硬顶-$K$情况。

**不对称检索区间**：分别对正负残差计算经验分位数$\widetilde{R}_t^+ = Q_{1-\alpha/2}^{w_t}\{e_i^+ : i \in N_K(t)\}$，$\widetilde{R}_t^- = Q_{1-\alpha/2}^{w_t}\{e_i^- : i \in N_K(t)\}$，构建检索区间$\widetilde{C}_t = [\widehat{Y}_t - \widetilde{R}_t^-, \widehat{Y}_t + \widetilde{R}_t^+]$。该区间捕获局部残差行为，但不提供覆盖率保证。

**规范化检索误差与校正**：对每个校准索引$j$，计算检索区间$\widetilde{C}_j$后的规范化检索误差$B_j = \max\left\{\frac{(Y_j - \widehat{Y}_j)_+}{\widetilde{R}_j^+}, \frac{(\widehat{Y}_j - Y_j)_+}{\widetilde{R}_j^-}\right\}$，该标量分数衡量实际残差相对于检索尺度的超出程度。基于校准集上$B_j$的经验分布，估计分位数校正因子$\widehat{c} = Q_{1-\alpha}(\{B_j : j \in \mathcal{I}_{\text{cal}}\})$。最终预测区间为$C_t^{\text{RCCP}}(\widehat{c}) = [\widehat{Y}_t - \widehat{c}\widetilde{R}_t^-, \widehat{Y}_t + \widehat{c}\widetilde{R}_t^+]$。校正因子$\widehat{c}>1$表示检索区间偏窄，$\widehat{c}<1$表示偏宽。

**算法伪代码**：Algorithm 1展示了两阶段过程：校准阶段依次计算检索区间、记录规范化误差并更新知识库，最终估计$\widehat{c}$；测试阶段对每个新时间点检索区间并缩放。知识库仅在目标值观测后更新，确保因果性。

**理论分析**：定理1给出覆盖率隙界$|\mathbb{P}_{\text{test}}\{Y_t \in C_t(\widehat{c})\} - q| \leq \rho_n + \frac{2L}{m}(e_n + r_n)$，其中$\rho_n$为校准-测试分数失配，$e_n$为经验校准误差，$r_n$为有限样本分位数水平误差。推论1表明当$\rho_n, e_n, r_n \to 0$时，RCCP渐近达到目标覆盖率$1-\alpha$，无需可交换性假设。

## 实验与结果
**数据集**：Air（小时级PM10，12个地点，35,064个点）、Solar（小时级DHI，50个地点，26,304个点）、Electricity（30分钟级电力传输，3,444个点）、Wind（小时级MWH，13,870个点）。每个数据集按40%/40%/20%时序划分训练、校准、测试集。

**预测器**：LSTM和Transformer骨干网络，隐藏维度128，批量大小256，训练150轮Adam优化器学习率$10^{-3}$。

**基线方法**：SCP（分裂共形预测）、EnbPI（在线自适应）、SPCI（序列共形预测）、NexCP（测试依赖加权）、HopCPT（Modern Hopfield网络加权）、ResCP（储层状态相似度加权）。所有方法使用相同时序划分、冻结点预测和随机种子，超参数在校准集上选择。

**评估指标**：经验覆盖率$\widehat{\text{Cov}}$、有符号覆盖隙$\Delta_{\text{Cov}}$、PI宽度（平均区间长度）、Winkler得分、校准时间（后预测计算时间）。
