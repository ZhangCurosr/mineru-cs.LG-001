# 论文速读：MARCO: CLICK-INTENT DECOMPOSITION FOR CALIBRATED ADS CONVERSION PREDICTION

## 一句话总结
MARCO通过将广告点击按用户意图（如高意图CTA点击 vs 低意图社交流量）分解为异构子群体，分别训练独立的CVR头并在推理时按预测的意图分布加权合成，消除了传统单头CVR模型因点击异质性导致的系统性组条件校准偏差。该方法在Meta生产平台上实现了点击转化率+2.80%和累计顶线指标+0.98%的显著提升。

## 研究问题与动机
1. **点击异质性被忽视**：工业广告排序系统虽将转化概率分解为CTR和CVR，但将所有点击视为同质事件，而现实中不同类型点击的实际转化率差异显著（高意图CTA点击转化率约为低意图社交流量的4倍）。
2. **系统性组条件偏差**：单一CVR头在混合点击群体上必然低估高意图点击、高估低意图点击，导致拍卖排序中被 inflated 的低意图分数挤占了高转化候选位。
3. **聚合校准掩盖内部失真**：反向误差在总体指标中相互抵消，使标准监控工具显示健康校准，形成"静默失败模式"（click-intent heterogeneity），单输出架构存在根本性的可观测障碍（Proposition 1）。
4. **既有方法无法突破结构限制**：多任务学习、MoE、事后校准等均仅增加模型容量或修改特征，但未改变单输出结构，受限于"点击前不可观测意图"的物理约束，无法实现群条件校准。

## 核心贡献（创新点）
1. **问题形式化与可观测性障碍证明**：首次识别点击意图异质性为系统性校准偏差的根因，并严格证明在 Proper Scoring Rule 和固定曝光时间特征下，任何单CVR输出无法同时对所有意图类别校准。与已有工作的本质区别：此前文献仅视此为容量问题，本文揭示其为结构性不可观测障碍。

2. **免费行为监督与机制隔离**：利用日志点击类型作为零成本监督信号，通过控制消融实验证明单输出架构即使叠加辅助意图任务、历史特征或MoE门控仍无法突破校准上界，而暴露per-intent输出的分解结构可消除>99%校准误差，参数增量<10⁻⁷%。与已有工作的本质区别：不是增强表征或路由网络，而是重构监督目标和输出层结构。

3. **生产级端到端系统设计**：提出"最后曝光×首次点击"信用归属策略（类比RL中TD(0)的低偏差低方差选择），并推导跨管道一致性条件（CTR/CVR训练与校准四端对齐），设计了冷启动协议和安全回退机制。与已有工作的本质区别：不仅提出模型，更解决了分布式工业系统中多管道协同的实际工程问题。

4. **理论基础与路由效率分析**：将意图分解形式化为总体水平类扩张（F⊆G），证明弱优性（Δ_F≥0）、严格正性（genericity）和路由单调性（Prop. 7），并引入路由效率参数η̂量化实际释放的理论空间比例。与已有工作的本质区别：首次为意图分解提供完整的统计学习理论分析框架。

## 方法详解
**核心公式**：Φ_MARCO(x) = Σₖ λ_k(x)·μ_k(x)，其中λ_k为意图k的CTR，μ_k为意图k的CVR，满足P̂(k|click,x)=λ_k/λ。

**免费行为监督**：训练时使用日志点击类型（如CTA tap vs social interaction）作为意图标签，每个per-intent CVR头μ_k仅在属于意图k的点击子集上训练；推理时意图标签不可观测，通过预测意图分布π̂_k = λ̂_k/λ̂进行加权合成。

**向量头架构**：在共享DNN骨干后，CTR和CVR模型各增加一个K维向量头（ℝ^d→ℝ^K），输出完整意图向量(λ₁,...,λ_K)和(μ₁,...,μ_K)，保留原始标量输出作为回退基线；相比独立训练K个模型，参数增量<10⁻⁷%，延迟不变。

**信用归属设计**（多曝光、多点击场景）：将转化分配建模为权重(w_i, v_{i,j})的交叉曝光与点击轴分配，权衡偏差与方差：曝光轴选最后曝光（低偏差，类比Monte Carlo），点击轴选首次点击（低方差，类比TD(0)），形成"last-impression, first-click"确定性策略。

**跨管道一致性条件**：CTR训练、CVR训练、CTR校准、CVR校准四个管道对每曝光i必须达成统一意图标签κ(i)，通过Click Metadata Table和去重缓存实现原子性写入和跨schema查找。

**安全回退**：Φ = Φ_MARCO + I(Φ_MARCO=0)·Φ_std，实验稀释导致意图预测消失时自动回退到标量基线。

**理论头room分析**：Δ_F = inf_{f∈F}R(f) - inf_{g∈G}R(g)，平方损失下精确等于L²投影能量‖P_Gμ - P_Fμ‖²；路由效率η̂ = 1 - ε_route/Δ_F，其中ε_route ≤ E[‖π̂ - π‖²·s²]，s²衡量意图间CVR异质性。

## 实验与结果
**数据集**：Meta生产广告平台，覆盖数亿用户的多周A/B测试，离线评估使用7天生产日志[17]。

**RQ1——群条件校准**（Table 2）：
| 模型 | 高意图校准误差消除 | 低意图校准误差消除 |
|------|---------------------|---------------------|
| Baseline (Pooled CVR) | 0% | 0% |
| + Auxiliary Intent Tasks | 0% | 0% |
| + Historical Intent Feature | 1% | 3% |
| + MoE on Historical Intent | 2% | 8% |
| **MARCO** | **>99%** | **>99%** |

单输出架构无论容量如何扩展，均受Proposition 1约束无法消除校准误差；MARCO以>10倍优势超越最强替代方案。

**RQ2——组成后曝光NE增益**（Table 3）：
- Base CTR + 无校准：+0.054% [0.043%, 0.067%]
- Base CTR + 联合CTR&CVR校准：**+0.223%** [0.210%, 0.235%]（其中CVR校准贡献+0.181%）
- Large CTR（5×容量）：+0.092% [0.067%, 0.112%]
- Oracle路由上限：+2.268% [2.235%, 2.302%]
- Routing效率从2.38%（Base）提升至4.06%（Large），验证Prop. 7

**RQ3——预曝光漏斗召回**：在O(10²)候选集规模下，价值加权召回提升+0.38%。

**RQ4——在线业务影响**：
- 多轮增量部署累计顶线指标：**+0.98%** [0.86%, 1.12%]
- 主广告位holdback实验：**点击转化率+2.80%** [2.50%, 3.10%]
- 自动回退触发率<0.1%

**离线NE增益（+0.223%）远低于在线转化增益（+2.80%）的原因**：①概率空间压缩（λ²缩放效应，λ≪1）；②拍卖再分配动力学（校准恢复使高意图候选系统性胜出，低意图候选被抑制）。

## 相关工作脉络
1. **ESMM [1] 与 ESCM2 [5] / DCMT [6]**：全空间多任务模型从曝光到转化进行垂直漏斗分解（PCT→PCR→CVR），关注曝光缺失和选择偏差；MARCO聚焦于点击后的意图分层，两者正交可组合。
2. **PLE [9] / MGMMoE [8] / PepNet [10]**：多任务学习和MoE架构通过共享专家+门控路由处理任务关系，但最终输出仍为单一预测标量，未触及监督目标的意图分解；MARCO从输出层重构入手，而非仅修改表征层。
3. **事后校准（Platt [11], Buckly [12], Calibrate Matters [13], Semantic Grouping [14]）**：基于预曝光特征对单标量概率进行保序或分桶校准，无法处理点击后不可观测的意图异质性，受限于Proposition 1的观测障碍。
4. **IntentRec [15]**：通过分层多任务学习预测用户会话意图以丰富特征表示，但预测组合公式未变，仍输出单一CVR；MARCO直接分解CVR输出头，从根本上重构评分函数。
5. **Post-stratification [3, 4]**：经典统计抽样中按已知分组变量调整估计，MARCO的意图分层是其动态版本，但意图是点击后结果（非曝光时已知），需通过CTR分解提供路由权重π_k。

## 局限性与未来方向
1. **当前仅部署于K=2二元粒度**：理论头room随意图细分单调递增，更细粒度的CTA子导航类型和Post-click交互信号（停留时长、完播率、有机互动）尚未充分利用。
2. **稀疏意图层的校准挑战**：随K增大，各意图桶样本量减少，长尾意图面临实时校准收敛困难，需开发抗稀疏的动态校准器。
3. **路由效率仍有提升空间**：当前η̂仅释放约2-4%的理论头room，CTR模型容量扩展是最高杠杆方向（Prop. 7），可进一步拉近Oracle上限。
4. **跨管道一致性的工程复杂度**：分布式环境下四管道严格对齐需要额外的缓存和一致性基础设施，细粒度意图会放大此类开销。

## 研究启发与可借鉴点
1. **免费行为监督的范式**：利用系统已有日志中的细粒度行为信号（无需额外标注）作为隐式监督目标，实现零成本的性能提升；可迁移至其他推荐/广告场景中利用隐含行为信号的类似建模。
2. **理论先验指导架构设计**：先证明"单输出不可校准"的观测障碍（Prop. 1），再从结构层面突破，而非盲目增加模型容量；这种"先证后建"的研究路径值得借鉴。
3. **离线指标与在线增益的解耦分析框架**：通过λ²缩放效应和拍卖再分配动力学的双层解释，阐明离线NE增益（+0.223%）与在线转化增益（+2.80%）的巨大差异，为评估广告模型提供更具洞察力的分析视角。
4. **Credit Attribution的偏差-方差权衡**：将多触点归因建模为RL中的return估计问题（Last-touch≈Monte Carlo低偏差，First-click≈TD(0)低方差），提供了系统化的策略选择框架。
5. **跨管道一致性条件的设计模式**：分布式ML系统中，多组件必须就共享语义达成一致；MARCO提出的四端一致性条件和去重缓存方案，为类似工业系统提供了可复用的工程范式。

## 关键术语表
**Click-Intent Heterogeneity（点击意图异质性）**：同一广告的不同点击类型（如CTA点击vs社交流量）具有显著不同的转化率，导致单一CVR模型产生系统性组条件偏差。

**Per-Intent Calibration（群条件校准）**：对每个意图子群体单独校准预测概率，使得预测值等于该群体的真实转化率，区别于总体聚合校准。

**Routing Efficiency η̂（路由效率）**：衡量实际推理时释放的理论头room比例，定义为η̂=1-ε_route/Δ_F，其中ε_route为由意图预测误差导致的路由成本。

**Credit Attribution（信用归属）**：在多曝光、多点击的用户转化旅程中，将一次转化事件按权重分配给各曝光和点击，用于生成训练目标。

**Normalized Entropy（NE，归一化熵）**：基于交叉熵的损失度量，NE=R(f)/H(ȳ)，用于评估广告转化概率预测质量，值越低越好。

**Weak Dominance（弱优性）**：意图分解后的假设类G包含原类F（F⊆G），因此在任何风险度量下最优风险不会高于原类（Δ_F≥0）。

**Observability Barrier（可观测性障碍）**：由于意图是点击后事件，在曝光时不可观测，任何仅基于曝光时间特征的单一输出模型无法同时满足所有意图类别的校准。

**Last-Impression First-Click Attribution**：MARCO采用的信用归属策略，选择最后一次曝光中的首次点击作为credited intent，兼顾上下文接近性（低偏差）和行为噪音最小化（低方差）。
